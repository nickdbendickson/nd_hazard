ND Dam Suite release 1.11 (2026-10-07)

- ND Dam Hazard Helper 2.22.0
- ND Breach Runner 3.12.0 (bundled LISFLOOD-FP)
- ND Dam Screening 0.20.0
- ND Data Updater 1.1.0

Install each zip in QGIS: Plugins > Manage and Install Plugins > Install from ZIP.

New in this release: keep-awake during long runs, near-dam refine off by default (fixes zero velocities), HEC-RAS export of culverts and bridges, opt-in clip pre-growth in Screening, Screening storage-leak fix, DWR unknowns and dugouts support.
